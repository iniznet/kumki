# Action hooks

Generated by `mahout-devtools`. Do not edit by hand; run `composer hooks:generate`.

Every hook name is a `public const` on a `Hooks` class; its `@action` or `@filter` docblock tag decides which of the two documents the entry lands in.
The other kind lives in `filters.md`.

| Constant | Hook | Arguments | Since | Description |
|---|---|---|---|---|
| `INIT` | `init` | — | 1.0 | Core's init. ContentProvider registers the declared content model here, after every provider booted, which is where a post type must be declared for the rest of the request to see it. |
| `ADMIN_MENU` | `admin_menu` | — | 1.0 | Core's admin menu. AdminProvider attaches the pages this plugin owns here; the field package attaches the panels and screens the declarations imply. |
| `PURGE` | `kumki/cache/purge` | `list<string> $keys` | 1.0 | The cache purge seam. This plugin owns the seam and emits this action when a content change invalidates a fragment; the client owns the endpoint that listens. No vendor purge API is ever called. Declared in this scaffold; the invalidation service that fires it belongs to a feature slice, and nothing fires it yet. |
